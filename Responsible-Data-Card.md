# Responsible Data Card

## 1. Dataset Information
- Dataset: Customer Churn Training Data
- Format: CSV
- Records: 12
- Columns: 7
- Purpose: Customer churn prediction

## 2. Data Features
- Customer ID
- Tenure Months
- Support Tickets
- Monthly Spend
- Last Login Days
- Plan Type
- Churned

## 3. Data Privacy
- Protect customer information.
- Do not share personal data publicly.
- Restrict unauthorized access.

## 4. Data Quality
- Check missing values.
- Remove duplicate records.
- Verify data accuracy.

## 5. Data Risks
- Small dataset size.
- Possible prediction bias.
- Data leakage risk.
- Unknown data collection consent.

## 6. Responsible Usage
- Use data only for learning.
- Avoid unfair predictions.
- Keep human supervision.
- Protect customer privacy.

## 7. Conclusion
Responsible data handling helps
build safer and more reliable
machine learning systems.
